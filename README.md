# HanBridge

HanBridge is a Windows-first bilingual AI input method prototype built on Weasel, librime, and rime-ice.

V1 behavior:

```text
type Chinese pinyin
  -> candidate 1: Chinese
  -> candidate 2: English translation
  -> choose either candidate normally
```

The English candidate is generated by an OpenAI-compatible Chat Completions API. DeepSeek and OpenCode Go presets are included.

## Requirements

- Windows 10 22H2 or Windows 11 x64
- Weasel 0.17.x
- rime-ice
- .NET 8 SDK for development
- A DeepSeek API key, an OpenCode Go API key, or another OpenAI-compatible endpoint

HanBridge does not bundle Weasel, librime, rime-ice, model weights, or Ollama.

## Build

```powershell
.\installer\Build-HanBridge.ps1
```

The self-contained Windows x64 build is written to `artifacts\publish\win-x64`.

## Install

Install Weasel and rime-ice first, then run:

```powershell
.\installer\Install-HanBridge.ps1
```

The installer:

- verifies Weasel 0.17.x and rime-ice;
- backs up `rime_ice.custom.yaml`;
- inserts one idempotent managed patch block;
- installs the Lua plugin;
- copies the tray app into `%LOCALAPPDATA%\HanBridge\app`;
- registers the current-user autostart entry;
- triggers Weasel deployment.

If a conflicting user patch already exists, installation stops rather than overwriting it.

## Configure

Open the HanBridge tray icon and select **设置**.

Presets:

- DeepSeek: `https://api.deepseek.com/chat/completions`, model `deepseek-flash`
- OpenCode Go: `https://opencode.ai/zen/go/v1/chat/completions`, model `deepseek-v4.1-flash`
- OpenCode Go model presets include `glm-5.3-flash`, `mimo-v2.6-flash`, `kimi-k3`, and `longcat-2.0`
- Custom: any OpenAI-compatible Chat Completions endpoint

Use `Ctrl+Alt+E` to toggle translation on or off. When translation is off, the Lua plugin performs no model requests.

## Uninstall

```powershell
.\installer\Uninstall-HanBridge.ps1
```

Program files, the autostart entry, and the managed Rime patch are removed. User Rime data is preserved by default. Use `-RemoveApiKeys`, `-RemoveCache`, or `-RemoveAllData` for explicit data removal.
